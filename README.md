# My Portfolio

A personal portfolio website designed to showcase my technical capabilities, projects, achievements, experiences, and interests as an AI and Machine Learning Engineer.

The portfolio is built with a strong focus on interactive UI, modern visual design, responsive layouts, and motion-driven user experiences.

## Overview

This portfolio serves as a central place to explore my:

- Professional profile and background
- Technical skills and capabilities
- AI, Machine Learning, and software projects
- Professional and extracurricular experiences
- Certifications and achievements
- Interests beyond technical work
- Contact and professional profiles

The website is designed to provide an interactive experience rather than functioning as a conventional static resume.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Tailwind CSS
- GSAP
- Motion
- OGL
- shadcn/ui

## Key Features

- Responsive portfolio experience across desktop, tablet, and mobile devices
- Interactive animations and transitions
- Motion-based content presentation
- Interactive project showcase
- Technical skills categorized by domain
- Education and experience sections
- Certifications and achievements showcase
- Photography and personal interests section
- Professional contact and social links
- Responsive navigation and layouts
- Modern dark-themed visual design
